# Example Usage (English)

## Example Request

Please read my project implementation first, with a focus on the LLM harness and the training pipeline.
Then draw a paper overview figure in an ACL / EMNLP-style visual language and save it as PDF.
I do not want it to feel too much like a generic flowchart, so please inspect the paper figures under the `papers` directory,
reduce text density, and depict each small module in a lightweight comic style.
Then refine the figure again by restoring the necessary core computations and formulas in the most important modules,
emphasizing the key contribution modules, and adding a mild hand-drawn touch so the overall figure looks more natural.
